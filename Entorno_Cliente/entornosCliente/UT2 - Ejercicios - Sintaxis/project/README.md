# Ejercicios de JavaScript · UT02

Proyecto local para practicar sintaxis de JavaScript: variables, tipos,
operadores, decisiones y bucles. Cada ejercicio vive en su propia carpeta
con dos archivos:

- `script.js` — aquí escribes tu solución. Empieza con el enunciado como
  comentario, para tenerlo siempre a la vista mientras programas.
- `index.html` — muestra el enunciado y ejecuta tu `script.js`, mostrando la
  salida en pantalla.

## Cómo usarlo

1. Abre esta carpeta completa en Visual Studio Code (`Archivo > Abrir carpeta...`).
2. Entra en la carpeta del ejercicio que quieras resolver y edita `script.js`.
3. Abre `index.html` de ese ejercicio en el navegador para ver el resultado:
   - **Opción rápida:** doble clic en el archivo `index.html` (funciona sin instalar nada).
   - **Opción alternativa:** instala la extensión **Live Server** en VS Code y haz clic derecho sobre `index.html` → "Open with Live Server".
4. Si tu script usa `prompt()` o `alert()`, el navegador mostrará cuadros de diálogo al cargar la página — respóndelos y verás el resultado en el panel de abajo.
5. Empieza por `index.html` en la raíz del proyecto: es el índice con los 25 ejercicios agrupados por bloque.

## Sobre algunos ejercicios

- Los ejercicios 1 a 9 y el 11 son sobre todo de reflexión: piden pensar la
  respuesta antes de comprobarla. Varios (4, 5, 6, 7, 8, 9, 11) ya llevan el
  código de partida cargado en `script.js`, listo para ejecutar.
- El ejercicio 3 repite literalmente el enunciado del ejercicio 1 en el
  documento original.
- El ejercicio 21 dice "modifica el ejercicio 1", pero probablemente se
  refiera a alguno de los ejercicios de edad (10 o 13). Se ha mantenido el
  texto tal cual aparece en el documento origina. Ambos casos están
  señalados con una nota dentro del propio ejercicio.

## Notas

- El resultado también puede verse con las herramientas de desarrollador del navegador (F12 → pestaña "Consola").
- No hace falta ningún paquete de Node ni servidor: todo funciona con HTML y JS planos, sin `fetch`, así que el doble clic siempre funciona.
