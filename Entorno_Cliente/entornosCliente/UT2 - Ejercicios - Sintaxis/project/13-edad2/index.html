EDAD2

Crea un script que pida al usuario que introduzca una edad y muestre el siguiente mensaje en función del número introducido:

  • 0-12: Niño
  • 13-25: Joven
  • 26-60: Adulto
  • >60: Jubilado

Dará un mensaje de error si:

  • no se introduce ninguna edad y se pulsa Aceptar
  • se introduce un texto y se pulsa Aceptar
  • se pulsa Cancelar
  • la edad es menor que 0
